# Contributing

Open an issue before substantial changes. Keep the package small and independent
of any application or HTTP client. Include tests for concurrency and cleanup
semantics when changing locking behavior. Run both test suites in README.md.

Never submit credentials, private hostnames, production logs or downloaded data.
Contributions are provided under the repository's Apache-2.0 license. By
contributing, you confirm you have the right to contribute the submitted code.
